# Why is My Website Slow? 🚀

A sleek, glassmorphism-inspired web tool designed to analyze frontend website performance, SEO metrics, and real-world Chrome User Experience (CrUX) field data using Google's PageSpeed Insights API.

![Project Preview](https://img.shields.io/badge/Status-Active-brightgreen)
![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20JavaScript-blue)

---

## 🌟 Features

- **Performance Auditing:** Fetches key Lighthouse metrics including First Contentful Paint (FCP), Largest Contentful Paint (LCP), Cumulative Layout Shift (CLS), and Total Blocking Time (TBT).
- **SEO & Accessibility Insights:** Evaluates document structure, meta descriptions, viewport tags, and accessibility best practices.
- **CrUX Field Data:** Displays real-world user metrics including Interaction to Next Paint (INP) and historical performance categories.
- **Dynamic Score Color Coding:** Automatically styles metrics with green (good), orange (average), or red (poor) based on performance scores.
- **Modern UI:** Futuristic dark-mode aesthetic with interactive hover effects and glassmorphism styling.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3 (Grid, Flexbox, Keyframes), Vanilla JavaScript (ES6+)
- **API:** [Google PageSpeed Insights API](https://developers.google.com/speed/docs/insights/v5/get-started)
- **Typography:** Google Fonts (`Orbitron`, `Happy Monkey`)

## 🚀 Getting Started

### Prerequisites
To run this project locally, all you need is a web browser.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/LostUchiha05/Why-is-my-Website-Slow.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Why-is-my-Website-Slow
   ```

3. **Open the project:**
   Simply double-click `index.html` or open it with the **Live Server** extension in Visual Studio Code.

---

## 📋 Usage

1. Enter any publicly accessible URL into the search input (e.g., `https://example.com`).
2. Click the **Analyze** button.
3. View the comprehensive audit divided into:
   - **Main Results:** High-level summary scores.
   - **Lab/Lighthouse Data:** In-depth technical speed metrics.
   - **SEO Data:** On-page optimization highlights.
   - **CrUX Data:** Real-world performance metrics from actual visitors.
